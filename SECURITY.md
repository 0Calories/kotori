# Security Policy

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues or pull requests.

Instead, submit a private report via [GitHub Private Vulnerability Reporting](https://github.com/0Calories/kotori/security/advisories/new) with:

- Affected component (`@kotori/backend`, `@kotori/app`, auth/session handling, infrastructure, etc.)
- Reproduction steps or proof-of-concept
- Potential impact

Reports are triaged promptly, and fixes are deployed continuously from `main` to `hellokotori.com` once verified.
